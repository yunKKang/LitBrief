# LitBrief · 文献简报：阅读页设计

更新：2026-11-12。网站名称已由用户确认。Lit 是 literature 的简写，Brief 对应定期的文献概况；本站按期刊与主题筛选，不使用热度排名。代码目录改为LitBrief；环境变量、浏览器主题存储键及部署服务名保留原前缀，避免影响现有配置。

## 依据与风格

- 浅色遵循用户指定的 Paper风格（用户此前确认的design.md v3，本页已列出完整项目规范）：暖纸色、近黑墨色、霞鹜文楷、细线与留白，替代此前大面积阅读卡片。
- [AIHOT](https://aihot.news/) 保留为侧边导航、主题筛选、按期阅读与目录结构的参考。此前输出到 `outputs/iteration2/` 的概念与截图属于旧版本，不是当前视觉规范。
- 深色延续 [课题组主页](https://sustainable-systems.world/) 的海军蓝背景。较深的侧栏区分导航，文章使用连续阅读面；暖白标题、灰蓝辅助文字、少量柔和暖色链接，不给每篇文章增加独立色块。
- 界面定位为研究者日常阅读的文献简报，视觉变化适中、动效低、内容密度适中。使用现有原生 HTML/CSS/JS，以排版和层级完成设计，不增加前端框架。

## 颜色与排版

| 用途 | 浅色 | 深色 |
|---|---|---|
| 阅读背景 | `#f6f1e7` | `#14213d` |
| 侧栏 | `#f1ebdf` | `#101b31` |
| 标题 | `#1a1816` | `#f0ece3` |
| 正文 | `#2e2b27` | `#d1d6de` |
| 辅助文字 | `#5e5950` | `#aab7c9` |
| 分隔线 | `#dcd3c3` | `#34435d` |
| 链接、选中状态 | `#b04a24` | `#deb6a5` |

标题、中文概况和说明性正文用霞鹜文楷 Regular / Medium，字重不超过 500；英文原题、期刊、日期、导航和表单标签用无衬线字体。站名 32px、页面标题 38px、文章标题 26px，概况 19px / 1.85 行高；桌面导航 15px，期刊名 15px 并使用强调色。阅读主栏最大 960px，审核工作台 1100px；长标题自然换行。

重要文献按日期、期刊与主题、中文标题、英文原题、短概况排列；入选依据折叠显示。其他相关文献用紧凑列表，支持进入详情。短评依据在板块与页脚明确标注。目录支持跳转，目标被筛选隐藏时自动清除筛选。

侧栏支持收起与展开，记住用户选择；收起后正文居中，保留展开入口与 aria-expanded 状态。手机端将侧栏放到顶部，导航可在自身区域横向滚动。输入字号至少 16px，主要主题、外观切换与阅读控件高度至少 44px；保留键盘焦点、跳到正文和减少动态效果支持。搜索无结果有明确提示与“清除筛选”，无匹配的板块暂时隐藏，相关文献计数随筛选更新。

## 字体与发布

`web/fonts/` 包含霞鹜文楷 v1.522 的 WOFF2 子集、清单和 OFL 许可，Regular 与 Medium 共约 3.1 MiB。通过同源 `@font-face` 加载，使用 `font-display: swap`，不依赖用户安装字体或外部 CDN。

子集覆盖 GB2312 常用字、标点与构建时已有文字；罕见新增字符可能暂用后备字体。需要更新时运行 `python scripts/build_fonts.py`，仅此开发命令需要本机原字体及 `fontTools`、`brotli`。服务运行不需要字体构建工具。

本机 `/reading` 展示真实 AI 推荐的待审试刊；公开导出只含已发布快照。`workflow.py export` 同步导出 CSS、字体与许可，包括期次和文章详情的相对路径。当前真实文章未发布，公开站点首页保持准备中。

## 本轮检查

- 48 项既有自动检查通过，含字体导出、公开数据隔离和字体路径边界。
- Tabbit 实测两种主题下 1440、1280、1024、768、700、390、320px 阅读页，无整页横向溢出；审核详情在 1440、390、320px 无横向溢出。
- 实测搜索无结果、清除筛选、供应链筛选、目录恢复隐藏条目、键盘展开入选依据、刷新保留外观、系统深浅切换。
- 根据浏览器实际计算样式核对标题、正文、期刊、辅助文字、链接与选中控件：浅色最低 4.59:1，深色最低 7.85:1。该检查覆盖所列元素，不等于完整无障碍认证。
- 独立虚构数据验证公开首页、文章详情、返回期次、归档搜索与选文标准导航；公开文章详情的两种字体均确认加载成功。未发布真实文献或调用 AI。

放大字号后的导航实测覆盖 320–1440px，展开和收起均无横向溢出，刷新保留选择。试刊页显示实时待复审数量，避免将 AI 推荐视为已人工批准。

## 图标导航修订

折叠控件使用Tabler侧栏图标，MIT许可随源码与静态导出保留。默认无文字与按钮框，44px点击区域；悬停和键盘聚焦显示状态提示，aria-label与aria-expanded同步。展开时图标与站名同排；桌面收起后保留64px细栏、正文重新居中且不增加顶部空白；手机保留76px简洁站名栏。无历史偏好时手机默认收起，已有选择保持。实测320–1440px展开/收起无整页溢出，Enter可操作且刷新保留选择。最新本地截图为outputs/design-review/icon-sidebar-*.png。
